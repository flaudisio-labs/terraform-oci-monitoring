# AGENTS.md

Terraform module library for OCI Monitoring alarms. There is no root module: reusable modules live
in `modules/alarms/<name>` and usage examples in `examples/<name>`.

## Commands

Tools and tasks are defined in `mise.toml`; run `mise install` if a tool is missing.

- `mise run lint` — runs `prek run --all-files` (Terraform fmt, terraform-docs, tflint, shellcheck,
  file hygiene).
- `mise run fmt` — formats all Terraform files.
- `mise run test` — Terratest suite in `test/`; deploys and destroys real OCI resources.
- Single test: `cd test && go test -run TestVMAlarms -v` (see the test note below).

There is no Makefile and no `pre-commit` command anymore; use the mise tasks.

## Repo-specific gotchas

- `terraform_docs` runs with `--lockfile=false`. Because the repo has no provider lock files,
  regenerating the READMEs rewrites the OCI provider version to `n/a`. Commit the regenerated
  READMEs instead of hand-editing inside the `BEGIN_TF_DOCS`/`END_TF_DOCS` markers.
- `examples/*/provider.tf` and `examples/*/.tflint.hcl` are symlinks into `_common/`. Edit the
  `_common` files, never the symlinks. The provider region is hardcoded to `sa-saopaulo-1`.
- Examples require `_oci_tenancy_ocid`, `_oci_user_ocid`, `_oci_fingerprint`,
  `_oci_private_key_path` and `compartment_id`. `*.tfvars` are gitignored, so pass variables with
  `TF_VAR_*` or `-var`.
- `test/` does not compile: both `vm_alarms_test.go` and `lb_alarms_test.go` define `TestVMAlarms`.
  Fix the duplicate name before running the suite.
- The Terratest tests `terraform apply` the examples (real OCI resources) and destroy them in
  cleanup, so they need valid OCI credentials. `GO_TEST_TIMEOUT` overrides the 30m default.
- Do not commit `*.tfvars` or private keys; the lint hooks reject keys and credentials.

## Release flow

- Use conventional commits; `CHANGELOG.md` is generated by `git-cliff`.
- `mise run bump-version:{major,minor,patch}` bumps `.bumpversion.toml`, tags `vX.Y.Z` and updates
  the changelog through a `setup_hooks` call to `mise run update-changelog`.
- `mise run git-push` pushes the current branch with tags.
- CI: `.github/workflows/lint.yml` runs `mise run lint` on PRs and pushes to `main`.
